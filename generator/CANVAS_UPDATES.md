# Canvas Updates v2.0

## Черно-белый угловатый дизайн

### Визуальные изменения
- **Цветовая схема**: полностью черно-белая (чистый #000000 и #FFFFFF)
- **Шрифт**: Courier New/Courier (моноширинный)
- **Формы**: прямоугольные, без скругления углов (border-radius: 0)
- **Переходы**: быстрые (0.1s) и линейные
- **Стиль текста**: UPPERCASE для всех надписей, letter-spacing для читабельности

### Элементы интерфейса
- **Панель управления**: черный фон, белая граница 2px
- **Кнопки**: угловатые, инверсия цвета при hover
- **Считыватель**: белый квадрат вместо круга
- **Слайдеры**: стандартные, минималистичные

## Поддержка пауз

### Структура данных
Каждый элемент в массиве имеет поле `type`:
- `"word"` - обычное слово
- `"pause"` - пауза между словами

```json
{
  "index": 1,
  "type": "pause",
  "word": "[PAUSE]",
  "filename": "0001_pause.wav",
  "start_time": 0.450,
  "end_time": 0.680
}
```

### Визуализация пауз
- Отображаются как маленькие серые квадраты (8x8px)
- При hover становятся белыми
- При чтении подсвечиваются белым
- Можно перетаскивать drag & drop
- Можно удалять через кнопку ×

### Воспроизведение
- Паузы проигрываются как обычные аудиофайлы
- Минимальная пауза между паузами: 50ms (адаптируется к скорости)
- Стандартная пауза между словами: 300ms

### API
Сервер возвращает поле `type` для каждого семпла:
```javascript
GET /api/samples/list
{
  "samples": [
    { "index": 0, "type": "word", "word": "привет", ... },
    { "index": 1, "type": "pause", "word": "[PAUSE]", ... }
  ]
}
```

### Счетчик
Отображает раздельно:
```
ДАННЫЕ: 145 слов, 89 пауз
```

## Совместимость

### Обратная совместимость
- Старые metadata.json без поля `type` автоматически определяются как `type: "word"`
- Canvas работает как со старыми, так и с новыми метаданными

### Требования
- metadata.json версии 3.1+ для полной поддержки пауз
- Аудиофайлы пауз в формате: `XXXX_pause.wav`

## Замена слов на похожие (NEW!)

### Функциональность
Кнопка **⇄ ЗАМЕНА СЛОВА** позволяет заменять случайное слово в выделенном лупе на максимально похожее из датасета.

### Алгоритм похожести
Приоритеты при поиске похожего слова:
1. **Часть речи (POS)** - критически важно (вес 100)
   - Слова с разными частями речи не рассматриваются
2. **Морфологические характеристики** (вес 10 каждая):
   - Род (gender)
   - Число (number)
   - Падеж (case)
   - Время (tense)
   - Лицо (person)
   - Одушевленность (animacy)
3. **Фонетические характеристики** (меньший вес):
   - Длина слова
   - Соотношение гласных/согласных
   - Процент гласных
4. **Штраф за частое использование** (вес -15 за каждое использование):
   - Слова, которые уже использовались в качестве замены, получают штраф
   - Формула: `final_score = similarity_score - (usage_count × 15)`
   - Это обеспечивает разнообразие в выборе замен

### Визуализация замен
- Замененные слова подкрашиваются оранжевым оттенком
- **Первая замена**: `rgba(255, 200, 100, 0.25)` - легкий оттенок
- **Повторные замены**: цвет становится плотнее
- **Максимум**: 5 уровней интенсивности (до `rgba(255, 200, 100, 0.85)`)
- При hover рамка становится оранжевой

### Использование
1. Установите цикл кнопками **[** и **]**
2. Нажмите **⇄ ЗАМЕНА СЛОВА**
3. Случайное слово в цикле заменится на похожее
4. Замененное слово будет подкрашено
5. При повторной замене того же слова цвет станет плотнее

### API эндпоинт
```javascript
POST /api/find-similar-word
{
  "target_word": {
    "word": "книга",
    "pos": "NOUN",
    "gender": "femn",
    // ... все характеристики слова
  },
  "exclude_indices": [0, 5, 10]
}

// Ответ:
{
  "success": true,
  "similar_word": { /* похожее слово */ },
  "similarity_score": 125.5,
  "original_word": "книга",
  "replaced_with": "газета"
}
```

### Примеры замен
- **книга** → **газета** (существительные, femn, sing)
- **говорить** → **сказать** (глаголы, infinitive)
- **красивый** → **большой** (прилагательные, masc, sing)

### Пример работы штрафа за использование
Предположим, есть 3 похожих существительных:
- **газета** - оценка похожести: 130
- **книга** - оценка похожести: 125
- **журнал** - оценка похожести: 120

**Первая замена:**
- Выбирается **газета** (оценка 130)

**Вторая замена (газета уже использовалась 1 раз):**
- **газета**: 130 - (1 × 15) = 115
- **книга**: 125 - 0 = 125 ← выбирается
- **журнал**: 120 - 0 = 120

**Третья замена (газета и книга уже использовались):**
- **газета**: 130 - (1 × 15) = 115
- **книга**: 125 - (1 × 15) = 110
- **журнал**: 120 - 0 = 120 ← выбирается

Таким образом, алгоритм автоматически обеспечивает разнообразие замен!

### Ограничения
- Цикл должен быть установлен (начало и конец)
- В цикле должно быть хотя бы одно слово (не пауза)
- Исключается само целевое слово из кандидатов

### Технические детали
Функция использует модуль `linguistic_features.py`:
- `find_most_similar_word()` - поиск похожего слова
- `calculate_similarity_score()` - оценка сходства
- Работает с полным набором лингвистических характеристик из metadata.json

## Автоматическая замена слов (NEW!)

### Функциональность
Режим автоматической замены позволяет автоматически заменять случайные слова в лупе с настраиваемым интервалом.

### Элементы управления

**1. Слайдер интервала**
- Диапазон: 0.5 - 10.0 секунд
- Шаг: 0.5 секунды
- По умолчанию: 2.0 секунды
- Можно регулировать во время работы автозамены

**2. Кнопка toggle**
- **⟳ АВТОЗАМЕНА: ВЫКЛ** (серая) - режим отключен
- **⟳ АВТОЗАМЕНА: ВКЛ** (черная) - режим активен

**3. Индикатор статуса**
- Показывает текущий статус и интервал
- **ВЫКЛ** - режим отключен
- **ВКЛ (2.0s)** (зеленый) - режим активен с интервалом 2.0s

### Как использовать

1. **Установите цикл** кнопками **[** и **]**
2. **Настройте интервал** слайдером (например, 2.0s)
3. **Нажмите "⟳ АВТОЗАМЕНА: ВЫКЛ"** для активации
4. Автоматическая замена начнется
5. **Нажмите снова** для остановки

### Поведение

- Замена происходит каждые N секунд (согласно слайдеру)
- Каждая замена выбирает случайное слово в лупе
- Применяется штраф за частое использование слов
- Замененные слова подкрашиваются с нарастающей интенсивностью
- Интервал можно изменять во время работы
- Автозамена останавливается при сбросе лупа

### Пример использования

**Сценарий:** Создание эволюционирующего текстового луп
1. Выделите фрагмент текста кнопками [ ]
2. Установите интервал 1.5s
3. Включите автозамену
4. Включите воспроизведение (▶ ИГРАТЬ)
5. Наблюдайте, как текст постепенно меняется каждые 1.5 секунды

### Комбинация с воспроизведением

Автозамена и воспроизведение работают независимо:
- Можно включить автозамену без воспроизведения
- Можно включить воспроизведение без автозамены
- Можно включить оба режима одновременно для живого изменения текста во время чтения

### Остановка автозамены

Автозамена автоматически останавливается при:
- Нажатии кнопки **⟳ АВТОЗАМЕНА: ВКЛ** (toggle off)
- Нажатии кнопки **⊗ СБРОС ЦИКЛА**

### Технические детали

```javascript
// Состояние автозамены
state.autoReplaceEnabled = false;  // Вкл/выкл
state.autoReplaceInterval = 2.0;   // Интервал в секундах
state.autoReplaceTimer = null;     // Таймер

// Запуск автозамены
function scheduleNextAutoReplace() {
    state.autoReplaceTimer = setTimeout(() => {
        replaceRandomWordInLoop();
        scheduleNextAutoReplace();  // Рекурсивно
    }, state.autoReplaceInterval * 1000);
}
```

### Особенности

- **Рекурсивное планирование**: каждая замена планирует следующую
- **Динамическая настройка**: интервал можно менять на лету
- **Безопасность**: автоматическая остановка при сбросе лупа
- **Визуальная обратная связь**: цветовая индикация и счетчики

## Сортировка лупа (NEW!)

### Функциональность
Позволяет отсортировать слова внутри установленного лупа по различным параметрам в выбранном порядке.

### Элементы управления

**Кнопка ⇅ СОРТИРОВАТЬ**
- Открывает модальное окно с параметрами сортировки
- Требует предварительно установленный луп

**Модальное окно:**
1. **ПАРАМЕТР** - по какому свойству сортировать:
   - Алфавит (слово) - по алфавитному порядку
   - Длина слова - по количеству символов
   - Часть речи (POS) - по грамматической категории
   - Процент гласных - по доле гласных букв
   - Соотношение гласных/согласных - по vowel_consonant_ratio
   - Длительность аудио - по продолжительности звучания

2. **ПОРЯДОК** - направление сортировки:
   - Возрастание (↑) - от меньшего к большему / от А до Я
   - Убывание (↓) - от большего к меньшему / от Я до А

3. **Кнопки:**
   - ✓ ПРИМЕНИТЬ - применить сортировку
   - ✗ ОТМЕНА - закрыть окно без изменений

### Как использовать

1. **Установите луп** кнопками **[** и **]**
2. **Нажмите "⇅ СОРТИРОВАТЬ"**
3. **Выберите параметр** сортировки в выпадающем списке
4. **Выберите порядок** (возрастание/убывание)
5. **Нажмите "✓ ПРИМЕНИТЬ"**

### Поведение

- **Сортируются только слова** - паузы остаются на своих местах
- **Сохраняется структура лупа** - начало и конец не меняются
- **Визуальное обновление** - изменения видны сразу после применения
- **Безопасность** - можно отменить через кнопку "✗"
- **Клик вне окна** - закрывает модальное окно

### Примеры использования

**Пример 1: Алфавитная сортировка**
- Параметр: Алфавит (слово)
- Порядок: Возрастание
- Результат: слова в лупе от А до Я

**Пример 2: По длительности**
- Параметр: Длительность аудио
- Порядок: Убывание
- Результат: сначала длинные слова, потом короткие

**Пример 3: По фонетике**
- Параметр: Процент гласных
- Порядок: Возрастание
- Результат: от слов с малым количеством гласных к словам с большим

### Технические детали

```javascript
// Сортировка по выбранному параметру
words.sort((a, b) => {
    let valueA, valueB;
    
    switch (parameter) {
        case 'word': valueA = a.item.word.toLowerCase(); break;
        case 'word_length': valueA = a.item.word_length; break;
        case 'duration': valueA = a.item.duration; break;
        // ... другие параметры
    }
    
    let comparison = valueA > valueB ? 1 : valueA < valueB ? -1 : 0;
    return order === 'asc' ? comparison : -comparison;
});
```

### Особенности

- **Неразрушающая операция**: можно повторно отсортировать
- **Сохранение пауз**: паузы между словами остаются на месте
- **Instant feedback**: результат виден сразу
- **Лог в консоль**: информация о количестве отсортированных слов
