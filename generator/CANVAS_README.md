# Canvas - Модуль визуализации текста

Интерактивный модуль для работы с текстом из семплов речи.

## Возможности

### 📖 Визуализация текста
- **Белый экран** с текстом по центру
- **Печатный шрифт** (serif) для лучшей читабельности
- **Настраиваемая ширина** колонки текста (300-1200px)
- Слова отображаются в их **естественном порядке** (по индексу)

### ▶️ Считыватель
- **Красная точка** над текущим словом
- **Автоматическое воспроизведение** аудио семплов
- **Настраиваемая скорость** чтения (0.1x - 3.0x)
- Плавная анимация перехода между словами

### 🎮 Интерактивность
- **Drag & Drop** - перетаскивайте слова для изменения порядка
- **Удаление слов** - наведите на слово и нажмите × 
- **Пауза/Воспроизведение** - контроль процесса чтения
- **Сброс** - возврат к началу текста

## Использование

### Запуск сервера

```bash
cd generator
python server.py --metadata ../output_audio/metadata.json --port 5000
```

### Открытие Canvas

Откройте в браузере:
```
http://127.0.0.1:5000/canvas
```

### Управление

#### Панель управления (слева)

1. **Скорость чтения** (0.1x - 3.0x)
   - 0.1x - очень медленно
   - 1.0x - нормальная скорость
   - 3.0x - очень быстро

2. **Ширина колонки** (300px - 1200px)
   - Настройте комфортную ширину для чтения

3. **Кнопки управления**
   - ▶ **Играть** - начать чтение
   - ⏸ **Пауза** - приостановить
   - ⏮ **Сброс** - вернуться к началу

#### Работа с текстом

**Перестановка слов:**
1. Зажмите слово мышкой
2. Перетащите на новое место
3. Отпустите кнопку мыши

**Удаление слов:**
1. Наведите курсор на слово
2. Нажмите на кнопку × сверху
3. Слово исчезнет из текста

**Воспроизведение:**
1. Нажмите ▶ Играть
2. Красная точка будет двигаться над словами
3. Каждое слово будет воспроизводиться с учетом скорости
4. Используйте ⏸ Пауза для остановки

## Технические детали

### Файлы модуля

```
generator/static/
├── canvas.html          # HTML страница
├── css/canvas.css       # Стили
└── js/canvas.js         # Логика работы
```

### API endpoints

Модуль использует существующие API:

- `GET /api/samples/list` - получение списка всех семплов
- `GET /api/samples/<filename>` - получение аудио файла семпла

### Архитектура

**State Management:**
```javascript
state = {
    samples: [],        // Оригинальные семплы
    words: [],         // Текущий порядок слов
    isPlaying: false,  // Статус воспроизведения
    currentIndex: 0,   // Текущее слово
    readingSpeed: 1.0, // Скорость
    columnWidth: 600   // Ширина колонки
}
```

**Основные функции:**
- `loadSamples()` - загрузка данных с сервера
- `renderText()` - отрисовка текста на экране
- `startReading()` / `pauseReading()` - управление воспроизведением
- `readNextWord()` - чтение следующего слова
- `playWordAudio()` - воспроизведение аудио семпла
- Drag & Drop handlers - перестановка слов

### Особенности реализации

1. **Web Audio API** используется для воспроизведения с переменной скоростью
2. **Drag and Drop API** для перестановки слов
3. **CSS transitions** для плавных анимаций
4. **Адаптивный дизайн** - работает на мобильных устройствах

## Кастомизация

### Изменение шрифта

В `canvas.css`:
```css
body {
    font-family: 'Ваш шрифт', serif;
}
```

### Изменение цветов

```css
.reader-indicator {
    background: #your-color;  /* Цвет точки-считывателя */
}

.word.reading {
    background-color: #your-color;  /* Подсветка читаемого слова */
}
```

### Изменение размера текста

```css
.text-column {
    font-size: 20px;  /* Измените размер */
    line-height: 2.2; /* И межстрочный интервал */
}
```

## Горячие клавиши

Планируется добавить в будущем:
- `Space` - пауза/воспроизведение
- `←/→` - предыдущее/следующее слово
- `Delete` - удалить выделенное слово
- `Ctrl+Z` - отменить последнее действие

## Известные ограничения

1. При перестановке слов во время воспроизведения может произойти сдвиг позиции считывателя
2. Аудио семплы должны быть доступны через API
3. Браузер должен поддерживать Web Audio API
