# Canvas - Быстрый старт 🚀

## Шаг 1: Подготовка данных

Убедитесь, что у вас есть обработанные семплы:

```bash
cd /Users/vankrav/Projects/ArtTECH/projects/stochastic_speech_machine/code
ls output_audio/
```

Должны быть файлы:
- ✅ `metadata.json` - метаданные семплов
- ✅ `samples/` - директория с .wav файлами

Если их нет, сначала обработайте аудио:
```bash
./run.sh assets/audio.mp3
```

## Шаг 2: Запуск Canvas

### Вариант A: Быстрый запуск (рекомендуется)

```bash
cd generator
./start_canvas.sh
```

### Вариант B: Ручной запуск

```bash
cd generator
python server.py --metadata ../output_audio/metadata.json --port 5000
```

## Шаг 3: Открытие в браузере

После запуска сервера откройте:

🎨 **Canvas:** http://127.0.0.1:5000/canvas

🎛️ **Generator:** http://127.0.0.1:5000/

## Основные действия

### 🎮 Воспроизведение

1. Нажмите **▶ Играть**
2. Красная точка начнет двигаться над словами
3. Каждое слово будет произноситься вслух
4. Нажмите **⏸ Пауза** для остановки

### ⚡ Скорость

Измените скорость чтения (0.1x - 3.0x):
- **0.5x** - медленно, детально
- **1.0x** - нормальная скорость
- **2.0x** - быстро

### 📐 Ширина колонки

Настройте комфортную ширину текста (300px - 1200px)

### 🔄 Перестановка слов (Drag & Drop)

1. **Наведите** на слово
2. **Зажмите** левую кнопку мыши
3. **Перетащите** на новое место
4. **Отпустите** кнопку

### ❌ Удаление слов

1. **Наведите** на слово
2. Появится кнопка **×** сверху
3. **Кликните** на нее
4. Слово исчезнет

### ⏮ Сброс

Нажмите **⏮ Сброс** чтобы вернуться к началу

## Примеры использования

### Создание поэтической композиции

1. Запустите Canvas
2. Прослушайте весь текст
3. Удалите лишние служебные слова (и, в, на, с)
4. Переставьте слова для создания ритма
5. Запустите снова и наслаждайтесь результатом

### Изучение структуры речи

1. Включите медленную скорость (0.3x)
2. Наблюдайте за движением считывателя
3. Обращайте внимание на длительность слов
4. Экспериментируйте с порядком

### Генерация случайных комбинаций

1. Произвольно переставьте несколько слов
2. Удалите часть текста
3. Прослушайте что получилось
4. Если не понравилось - обновите страницу для сброса

## Возможные проблемы

### Ошибка: "Ошибка загрузки данных"

**Причина:** Сервер не запущен или metadata.json не найден

**Решение:**
```bash
# Убедитесь что сервер запущен
cd generator
./start_canvas.sh

# Проверьте наличие metadata.json
ls -la ../output_audio/metadata.json
```

### Аудио не воспроизводится

**Причина:** Файлы семплов отсутствуют

**Решение:**
```bash
# Проверьте наличие .wav файлов
ls -la ../output_audio/samples/ | head -20

# Должно быть 487 файлов (или столько, сколько слов)
```

### Браузер не поддерживается

**Причина:** Старая версия браузера

**Решение:** Используйте современный браузер:
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+
