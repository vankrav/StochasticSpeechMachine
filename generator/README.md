# 🎛️ Генератор стохастической речи

Веб-инструмент для интерактивной генерации стохастической речи с настраиваемыми правилами.

## Описание

Генератор позволяет создавать новые речевые последовательности, комбинируя слова из исходной записи по различным акустическим, эмоциональным, фонетическим и грамматическим правилам.

**Принцип работы:**
- Слова теряют коммуникативную функцию и становятся звуковыми событиями
- Переход между словами осуществляется по настраиваемым правилам
- Вы контролируете вес каждого правила и степень хаотичности (температуру)

## Установка

### 1. Установка зависимостей

```bash
pip install flask flask-cors numpy
```

### 2. Структура

Убедитесь, что у вас есть:
- `metadata.json` - метаданные семплов (из основного процессора)
- `samples/` - директория с аудио файлами слов

## Запуск

### Базовый запуск

```bash
cd generator
python server.py --metadata ../output_audio/metadata.json
```

Затем откройте в браузере: http://127.0.0.1:5000

### Параметры запуска

```bash
python server.py --metadata <путь> --port <порт> --host <хост>
```

**Примеры:**

```bash
# С указанием порта
python server.py --metadata ../output_audio/metadata.json --port 8080

# Доступ извне (не только localhost)
python server.py --metadata ../output_audio/metadata.json --host 0.0.0.0
```

## Использование

### 1. Инициализация

1. Откройте веб-интерфейс в браузере
2. Укажите путь к `metadata.json`
3. Нажмите "Загрузить"

### 2. Добавление правил

Нажмите **"+ Добавить правило"** и выберите из категорий:

#### 🎵 Акустические правила

- **Близость pitch** - выбирает слова с близкой высотой тона
  - `max_diff` - максимальная разница в Hz
  
- **Направление pitch** - движение вверх/вниз/волной
  - `direction` - 'ascending' | 'descending' | 'wave'
  - `step` - минимальный шаг в Hz

- **Ритм длительности** - паттерн длинных/коротких слов
  - `pattern` - массив [1.0, 0.5, 1.0, 0.5]

- **Волна громкости** - crescendo/diminuendo/wave
  - `wave_type` - 'crescendo' | 'diminuendo' | 'wave'

- **Близость тембра** - похожие по MFCC коэффициентам
  - `threshold` - порог сходства (0-1)

#### 😊 Эмоциональные правила

- **Эмоциональная волна** - циклическое движение по эмоциям
  - `wave` - ['positive', 'neutral', 'negative']

- **Контраст эмоций** - чередование противоположных

- **Градиент эмоций** - плавный переход негатив→позитив
  - `direction` - 'ascending' | 'descending'

#### 🔤 Фонетические правила

- **Аллитерация** - повторение первой буквы

- **Гласные/Согласные** - работа с соотношением
  - `mode` - 'alternating' | 'increasing' | 'decreasing'

- **Звонкость/Глухость** - чередование

#### 📝 Грамматические правила

- **Паттерн частей речи** - NOUN→VERB→ADJF
  - `pattern` - ['NOUN', 'VERB', 'NOUN']

- **Существительное/Глагол** - простое чередование

### 3. Настройка параметров

**Температура (хаотичность):**
- `0.1` - детерминированный выбор (всегда лучший)
- `1.0` - стандартная случайность
- `2.0` - максимальный хаос

**Вес правила:**
- Контролирует влияние правила на выбор
- `0.0` - правило не влияет
- `1.0` - стандартный вес
- `2.0` - сильное влияние

### 4. Генерация

**Следующий семпл:**
- Нажмите ▶ "Следующий" для генерации одного слова

**Последовательность:**
- Установите длину (5-50 слов)
- Нажмите 📝 "Последовательность"
- Система автоматически воспроизведет всю цепочку

**Сброс:**
- 🔄 "Сброс" очищает историю и контекст

## Архитектура

### Backend (Python/Flask)

```
generator/
├── server.py           # Flask API сервер
├── generator.py        # Движок генерации
└── rules/              # Модули правил
    ├── base.py         # Базовый класс Rule
    ├── acoustic.py     # Акустические правила
    ├── emotional.py    # Эмоциональные правила
    ├── phonetic.py     # Фонетические правила
    └── grammatical.py  # Грамматические правила
```

### Frontend (HTML/CSS/JS)

```
static/
├── index.html          # Главная страница
├── css/
│   └── style.css       # Стили
└── js/
    └── app.js          # Логика интерфейса
```

### API Endpoints

```
POST /api/init                  # Инициализация генератора
GET  /api/rules/available       # Список доступных правил
POST /api/rules/add             # Добавить правило
POST /api/rules/update          # Обновить параметры
POST /api/rules/remove          # Удалить правило
GET  /api/rules/list            # Текущие правила
POST /api/generate/next         # Следующий семпл
POST /api/generate/sequence     # Последовательность
POST /api/temperature           # Установить температуру
POST /api/reset                 # Сброс состояния
GET  /api/samples/<filename>    # Получить аудио файл
```

## Расширение

### Создание своего правила

1. Создайте класс, наследующий `Rule`:

```python
from rules.base import Rule

class MyCustomRule(Rule):
    def __init__(self, my_param=1.0, **kwargs):
        super().__init__(name="Мое правило", my_param=my_param, **kwargs)
    
    def score(self, current, candidate, context):
        # Ваша логика оценки
        # Возвращает float от 0.0 до 1.0
        return 0.5
```

2. Добавьте в `rules/__init__.py`:

```python
from .my_module import MyCustomRule

__all__ = [..., 'MyCustomRule']
```

3. Зарегистрируйте в `server.py`:

```python
rule_classes = {
    ...
    'my_custom': MyCustomRule
}
```

4. Добавьте в `static/js/app.js`:

```javascript
availableRules.custom = [
    {id: 'my_custom', name: 'Мое правило', params: ['my_param']}
];
```

## Советы по использованию

### Экспериментирование

1. **Начните с одного правила** - понаблюдайте за поведением
2. **Добавляйте постепенно** - комбинируйте 2-3 правила
3. **Играйте с весами** - баланс между правилами важнее их количества
4. **Меняйте температуру** - влияет на предсказуемость

### Интересные комбинации

- **Эмоции + Pitch** - эмоциональная окраска + мелодичность
- **Тембр + Ритм** - звуковая текстура
- **Грамматика + Фонетика** - структура + звучание
- **Контраст + Волна** - динамика и драматургия

### Проблемы и решения

**Нет разнообразия:**
- Увеличьте температуру
- Уменьшите веса строгих правил
- Добавьте правила из разных категорий

**Слишком хаотично:**
- Уменьшите температуру
- Увеличьте вес одного основного правила
- Используйте правила с четкими паттернами

**Не воспроизводится аудио:**
- Проверьте путь к `samples/`
- Убедитесь, что файлы `.wav` существуют
- Проверьте консоль браузера на ошибки
