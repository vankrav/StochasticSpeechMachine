# Stochastic Speech Machine

Программа для разбивки аудиозаписей на отдельные слова с созданием метаданных для каждого семпла.

## Описание

**Stochastic Speech Machine** анализирует аудиозаписи, распознает речь, разбивает на отдельные слова и создает богатые структурированные метаданные.

### Рассчитываемые характеристики

**Акустические (~25 параметров):**
- **Амплитуда/громкость**: RMS, пиковая амплитуда, относительная громкость
- **Длительность**: абсолютная и относительная (% от общей)
- **Основная частота**: средняя, мин, макс, std, относительная
- **Спектральные**: centroid (яркость), bandwidth, flatness (шумность), rolloff
- **MFCC**: 13 коэффициентов тембра
- **Энергетика**: время атаки, изменчивость огибающей
- **Звонкость**: zero crossing rate

**Лингвистические (~15 параметров):**
- **Морфология**: часть речи, род, число, падеж, время (для глаголов)
- **Нормальная форма** слова
- **Фонетика**: длина слова, количество гласных/согласных/звонких/глухих
- **Соотношения**: процентное соотношение разных типов букв

**Эмоциональные (7 параметров):**
- **Сентимент**: positive/negative/neutral/skip/speech (через RuBERT)
- **Уверенность**: score модели (0-1)
- **Вероятности**: для каждого из 5 классов эмоций

## Особенности

- **Детальное логирование** - видите каждый этап обработки
- **Распознавание речи** через Vosk (офлайн, точные временные метки)
- **Поддержка больших файлов** - прогресс-бар при обработке
- **Расширяемая архитектура** - легко добавлять новые характеристики
- **Экспорт метаданных** в JSON формате

## Установка

### 1. Активация виртуального окружения

```bash
source .venv/bin/activate
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

**Зависимости включают:**
- `vosk` - распознавание речи
- `librosa` - акустический анализ
- `pymorphy3` - морфологический анализ (совместим с Python 3.11)
- `transformers` + `torch` - анализ эмоций (RuBERT)
- `numpy`, `soundfile` - обработка аудио

**Примечание:** Первый запуск займет больше времени, т.к. модель RuBERT (~500MB) будет скачана автоматически.

### 3. Установка ffmpeg

Необходим для работы с различными аудиоформатами:

**macOS:**
```bash
brew install ffmpeg
```

**Linux:**
```bash
sudo apt-get install ffmpeg
```

### 4. Установка моделей

Используйте скрипт для автоматической установки обеих моделей:

```bash
chmod +x setup_model.sh
./setup_model.sh
```

Скрипт автоматически установит:
- **Vosk** (~45MB) - модель распознавания речи в `./models/`
- **RuBERT** (~500MB) - модель анализа эмоций в `~/.cache/huggingface/`

Это может занять несколько минут в зависимости от скорости интернета.
- Проверит корректность установки

**Альтернативно:** можно скачать модель вручную
- Русский: https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
- Английский: https://alphacephei.com/vosk/models/vosk-model-small-en-us-0.15.zip

И распаковать в директорию `./models/`

## Использование

### Базовый пример

```bash
# Модель подхватывается автоматически из ./models/
./run.sh input_audio.mp3

# Или напрямую через Python (нужно указать модель)
python speech_processor.py input_audio.mp3 --model ./models/vosk-model-small-ru-0.22
```

### Параметры

```
positional arguments:
  audio_file            Путь к входному аудиофайлу (WAV, MP3, FLAC и др.)

options:
  -h, --help            Показать справку
  -m, --model PATH      Путь к модели Vosk (обязательно)
  -o, --output DIR      Директория для вывода (по умолчанию: output_<filename>)
  -r, --sample-rate HZ  Частота дискретизации (по умолчанию: 16000)
  -v, --verbose         Подробный вывод (DEBUG режим)
```

### Примеры использования

**Базовое использование (модель находится автоматически):**
```bash
./run.sh recording.wav
./run.sh podcast.mp3 -v
./run.sh audio.flac -o my_output
```

**С явным указанием модели:**
```bash
./run.sh recording.wav --model ./models/vosk-model-small-ru-0.22
```

**С дополнительными параметрами:**
```bash
# Подробный вывод
./run.sh audio.mp3 -v

# Свой sample rate
./run.sh audio.mp3 --sample-rate 22050

# Указать выходную директорию
./run.sh audio.mp3 --output my_results
```

### Описание основных полей

**Базовые:**
- `index` - порядковый номер слова
- `word` - распознанное слово
- `filename` - имя WAV-файла семпла
- `start_time` / `end_time` - временные метки
- `confidence` - уверенность распознавания (0.0-1.0)

**Акустические:**
- `duration` / `duration_relative` - длительность (абс. и %)
- `rms` / `rms_relative` / `peak_amplitude` - громкость
- `pitch_mean` / `pitch_min` / `pitch_max` / `pitch_std` / `pitch_relative` - частота
- `spectral_*` - спектральные характеристики
- `mfcc_mean` - тембр (13 коэффициентов)
- `attack_time` / `envelope_variance` - энергетика
- `zero_crossing_rate` - звонкость/шумность

**Лингвистические:**
- `normal_form` - нормальная форма слова
- `pos` - часть речи (NOUN, VERB, ADJF и т.д.)
- `gender` / `number` / `case` - морфологические признаки
- `tense` / `person` - для глаголов
- `word_length` - длина слова
- `vowels_count` / `consonants_count` - количество букв типов
- `voiced_consonants_count` / `voiceless_consonants_count`
- `vowels_percent` / `consonants_percent` / и др. - процентные соотношения
- `vowel_consonant_ratio` - соотношение гласных к согласным

**Эмоциональные:**
- `sentiment` - тип эмоции ("positive", "negative", "neutral", "skip", "speech")
  - positive/negative/neutral - основные эмоции
  - speech - речевые акты (приветствия, прощания)
  - skip - неопределенные
- `sentiment_score` - уверенность модели (0.0-1.0)
- `negative_prob` / `neutral_prob` / `positive_prob` / `skip_prob` / `speech_prob` - вероятности всех классов

## Архитектура

Программа состоит из модульных функций:

1. **load_audio()** - загрузка и конвертация аудио
2. **recognize_words_with_timestamps()** - распознавание речи через Vosk
3. **extract_and_save_samples()** - извлечение и сохранение семплов
4. **save_metadata()** - сохранение метаданных в JSON

Каждая функция логирует свой прогресс, что позволяет отслеживать выполнение на больших файлах.

## Troubleshooting

**Ошибка: "Модель Vosk не найдена"**
```bash
# Установите модель
./setup_model.sh

# Проверьте, что модель установлена
ls -la ./models/
```

**Ошибка: "No module named 'vosk'"**
```bash
# Убедитесь что виртуальное окружение активировано
source .venv/bin/activate
pip install -r requirements.txt
```

**Ошибка при скачивании модели**
```bash
# Скачайте модель вручную
# https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
# Затем распакуйте в ./models/
```

**Медленная обработка**
- Используйте меньший sample rate (8000 Hz): `./run.sh audio.mp3 --sample-rate 8000`
- Используйте "small" модель вместо "large"
- Проверьте доступные ресурсы системы
