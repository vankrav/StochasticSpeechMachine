# 📊 Руководство по метаданным

Подробное описание всех характеристик в файле `metadata.json`.

## 📋 Общая структура

### Метаинформация (корневой уровень)

| Поле | Тип | Описание |
|------|-----|----------|
| `source_file` | string | Полный путь к исходному аудиофайлу |
| `sample_rate` | integer | Частота дискретизации (обычно 16000 Hz) |
| `total_words` | integer | Общее количество распознанных слов |
| `metadata_version` | string | Версия схемы метаданных (текущая: 3.0) |
| `description` | string | Описание содержимого метаданных |
| `features` | object | Список типов характеристик |
| `models` | object | Информация об используемых моделях |
| `samples` | array | Массив объектов с характеристиками каждого слова |

---

## 🎯 Характеристики слова (объект в `samples[]`)

### 1. БАЗОВАЯ ИНФОРМАЦИЯ

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `index` | integer | Порядковый номер слова в речи (начинается с 0) | `0` |
| `word` | string | Распознанное слово | `"привет"` |
| `filename` | string | Имя файла с аудио этого слова | `"0042_привет.wav"` |
| `start_time` | float | Время начала слова (секунды от начала файла) | `12.34` |
| `end_time` | float | Время окончания слова (секунды) | `12.78` |
| `confidence` | float | Уверенность распознавания Vosk (0.0-1.0) | `0.95` |

---

### 2. АКУСТИЧЕСКИЕ ХАРАКТЕРИСТИКИ

#### 2.1 Временные характеристики

| Поле | Описание | Единицы | Что показывает |
|------|----------|---------|----------------|
| `duration` | Длительность звучания слова | секунды | Как долго произносится слово |
| `duration_relative` | Относительная длительность | безразмерная | Отношение к средней длительности всех слов. >1 = дольше среднего, <1 = короче |

**Применение:** Определение темпа речи, акцентов, эмоциональных пауз.

---

#### 2.2 Амплитудные характеристики (громкость)

| Поле | Описание | Диапазон | Что показывает |
|------|----------|----------|----------------|
| `rms` | Root Mean Square - среднеквадратичная амплитуда | 0.0-1.0 | Средняя "мощность" звука |
| `peak_amplitude` | Максимальная амплитуда | 0.0-1.0 | Самый громкий момент в слове |
| `rms_relative` | Относительная громкость | безразмерная | Отношение к средней громкости. >1 = громче, <1 = тише |

**Применение:** 
- Определение акцентированных слов (высокий rms)
- Эмоциональность (громкие слова часто эмоциональны)
- Нормализация громкости при генерации

**Пример:**
- `rms: 0.05` - громкое слово
- `rms: 0.01` - тихое слово

---

#### 2.3 Частотные характеристики (высота тона)

| Поле | Описание | Единицы | Что показывает |
|------|----------|---------|----------------|
| `pitch_mean` | Средняя частота основного тона | Hz (Герцы) | Средняя высота голоса |
| `pitch_min` | Минимальная частота | Hz | Самый низкий тон |
| `pitch_max` | Максимальная частота | Hz | Самый высокий тон |
| `pitch_std` | Стандартное отклонение частоты | Hz | Насколько "скачет" тон |
| `pitch_relative` | Относительная высота | безразмерная | Отношение к средней высоте голоса |

**Применение:**
- **Эмоции:** Высокий pitch = восторг, удивление; Низкий = грусть, серьёзность
- **Вопросы:** Обычно pitch повышается к концу
- **Пол:** Мужской голос ~85-180 Hz, женский ~165-255 Hz
- **Интонация:** Большой pitch_std = выразительная речь

**Пример:**
- `pitch_mean: 200` Hz - женский голос / детский
- `pitch_mean: 120` Hz - мужской голос
- `pitch_std: 50` - очень выразительное произношение
- `pitch_std: 10` - монотонное произношение

---

#### 2.4 Спектральные характеристики (тембр)

| Поле | Описание | Что показывает |
|------|----------|----------------|
| `spectral_centroid` | "Центр массы" спектра | Яркость звука. Высокое значение = "яркий" звук (много высоких частот) |
| `spectral_bandwidth` | Ширина спектра | Богатство тембра. Большое значение = "насыщенный" звук |
| `spectral_flatness` | Плоскостность спектра (0-1) | Близость к белому шуму. Близко к 0 = тональный звук (гласные), близко к 1 = шумный (согласные) |
| `spectral_rolloff` | Частота, ниже которой 85% энергии | Граница между основным звуком и обертонами |

**Применение:**
- Различение гласных (низкий flatness) и согласных (высокий flatness)
- Определение "светлых" (высокий centroid) и "тёмных" (низкий centroid) звуков
- Анализ качества звука и артикуляции

**Пример:**
- Гласная "а": `spectral_flatness: 0.01-0.05` (тональный звук)
- Согласная "ш": `spectral_flatness: 0.3-0.6` (шумный звук)

---

#### 2.5 MFCC (Mel-Frequency Cepstral Coefficients)

| Поле | Описание | Что показывает |
|------|----------|----------------|
| `mfcc_mean` | Массив из 13 коэффициентов | Уникальная "подпись" тембра голоса и звука |

**Применение:**
- **Идентификация говорящего** - MFCC уникальны для каждого голоса
- **Распознавание фонем** - разные звуки имеют разные MFCC
- **Машинное обучение** - основные признаки для классификации звуков
- **Синтез речи** - сохранение характера голоса

**Структура:**
- **MFCC[0]** - общая энергия (обычно большое отрицательное число)
- **MFCC[1-2]** - основные формантные частоты (самые важные для речи)
- **MFCC[3-12]** - детали тембра и артикуляции

**Пример использования:**
Если нужно найти похожие по звучанию слова, сравнивайте расстояние между MFCC векторами.

---

#### 2.6 Энергетический контур

| Поле | Описание | Что показывает |
|------|----------|----------------|
| `attack_time` | Время нарастания звука | Как быстро звук достигает максимума. Короткое = резкое произношение, длинное = мягкое |
| `envelope_variance` | Изменчивость огибающей | Насколько "неровный" звук. Высокое значение = динамичное произношение |

**Применение:**
- **Акцентирование:** Короткий attack_time = акцентированное слово
- **Эмоции:** Высокая variance = эмоциональное произношение
- **Артикуляция:** Помогает различать взрывные (короткий attack) и сонорные (длинный attack) согласные

---

#### 2.7 Звонкость / Шумность

| Поле | Описание | Диапазон | Что показывает |
|------|----------|----------|----------------|
| `zero_crossing_rate` | Скорость пересечения нуля | 0.0-1.0 | Близко к 0 = звонкий звук (гласные), близко к 1 = глухой/шумный (согласные) |

**Применение:**
- Различение звонких и глухих согласных
- Определение вокализованных участков
- Анализ артикуляции

**Пример:**
- `zcr: 0.05` - звонкая гласная "а"
- `zcr: 0.3` - глухая согласная "с"

### 3. ЛИНГВИСТИЧЕСКИЕ ХАРАКТЕРИСТИКИ

#### 3.1 Морфологический анализ

| Поле | Описание | Возможные значения | Пример |
|------|----------|-------------------|--------|
| `normal_form` | Начальная форма слова | любое слово | "бежать" для "бежал" |
| `pos` | Часть речи | NOUN, VERB, ADJF, ADJS, COMP, INFN, PRTF, PRTS, GRND, NUMR, ADVB, NPRO, PRED, PREP, CONJ, PRCL, INTJ | `"VERB"` |
| `animacy` | Одушевлённость | anim, inan, null | `"anim"` для "кошка" |
| `gender` | Род | masc, femn, neut, null | `"masc"` для "стол" |
| `number` | Число | sing, plur, null | `"sing"` для "дом" |
| `case` | Падеж | nomn, gent, datv, accs, ablt, loct, voct, gen2, acc2, loc2, null | `"nomn"` |
| `tense` | Время (для глаголов) | past, pres, futr, null | `"past"` |
| `person` | Лицо (для глаголов) | 1per, 2per, 3per, null | `"1per"` |

**Части речи (подробно):**
- **NOUN** - существительное (дом, кошка)
- **VERB** - глагол (идти, делать)
- **ADJF** - прилагательное (полное) (красивый, большой)
- **ADJS** - прилагательное (краткое) (красив, велик)
- **COMP** - компаратив (больше, лучше)
- **INFN** - инфинитив (бежать, думать)
- **PRTF** - причастие (полное) (бегущий, прочитанный)
- **PRTS** - причастие (краткое) (прочитан, сделан)
- **GRND** - деепричастие (бегая, думая)
- **NUMR** - числительное (три, пятый)
- **ADVB** - наречие (быстро, тут)
- **NPRO** - местоимение (я, ты, он)
- **PRED** - предикатив (можно, нужно)
- **PREP** - предлог (в, на, под)
- **CONJ** - союз (и, но, или)
- **PRCL** - частица (же, ли, вот)
- **INTJ** - междометие (ой, ах)

**Применение:**
- Синтаксический анализ предложений
- Определение стиля речи (много прилагательных = художественный)
- Генерация согласованных текстов
- Поиск по грамматическим категориям

---

#### 3.2 Фонетический анализ

| Поле | Описание | Что показывает |
|------|----------|----------------|
| `word_length` | Количество букв в слове | Сложность слова |
| `vowels_count` | Количество гласных | Вокализованность |
| `consonants_count` | Количество согласных | Артикуляционная сложность |
| `voiced_consonants_count` | Звонкие согласные (б, в, г, д, ж, з, л, м, н, р) | |
| `voiceless_consonants_count` | Глухие согласные (к, п, с, т, ф, х, ц, ч, ш, щ) | |

**Применение:**
- Оценка читаемости (длинные слова сложнее)
- Анализ звучности (много гласных = звучное)
- Прогнозирование длительности (больше согласных = дольше произносится)

---

#### 3.3 Фонетические соотношения

| Поле | Описание | Диапазон | Что показывает |
|------|----------|----------|----------------|
| `vowels_percent` | Процент гласных | 0-100 | Вокализованность слова |
| `consonants_percent` | Процент согласных | 0-100 | Артикуляционная насыщенность |
| `voiced_percent` | Процент звонких букв | 0-100 | Звонкость слова |
| `voiceless_percent` | Процент глухих букв | 0-100 | Глухость слова |
| `vowel_consonant_ratio` | Отношение гласных к согласным | 0-∞ | Баланс звучания |

**Применение:**
- Сложность произношения (много согласных = сложнее)
- Музыкальность речи (высокий vowels_percent = певучее)
- Энергетика (звонкие требуют больше энергии)

**Пример:**
- "мама": `vowel_consonant_ratio: 1.0` (50% гласных)
- "страсть": `vowel_consonant_ratio: 0.17` (много согласных)

### 4. ЭМОЦИОНАЛЬНЫЕ ХАРАКТЕРИСТИКИ

#### 4.1 Сентимент (RuBERT модель)

| Поле | Описание | Возможные значения |
|------|----------|--------------------|
| `sentiment` | Эмоциональная окраска слова | positive, negative, neutral, skip, speech |
| `sentiment_score` | Уверенность модели | 0.0-1.0 |

**Типы сентимента:**
- **positive** - позитивные эмоции (отлично, радость, прекрасно)
- **negative** - негативные эмоции (ужасно, плохо, грустно)
- **neutral** - нейтральные (стол, идти, когда)
- **speech** - речевые акты (привет, спасибо, пожалуйста)
- **skip** - неопределённые / смешанные

**Применение:**
- Анализ тональности речи
- Эмоциональная окраска генерируемого текста
- Детекция настроения говорящего
- Выделение эмоционально значимых моментов

---

#### 4.2 Вероятности классов

| Поле | Описание | Диапазон |
|------|----------|----------|
| `negative_prob` | Вероятность негатива | 0.0-1.0 |
| `neutral_prob` | Вероятность нейтральности | 0.0-1.0 |
| `positive_prob` | Вероятность позитива | 0.0-1.0 |
| `skip_prob` | Вероятность неопределённости | 0.0-1.0 |
| `speech_prob` | Вероятность речевого акта | 0.0-1.0 |

**Применение:**
- Более тонкий анализ (слово может быть 60% позитивным и 40% нейтральным)
- Обнаружение неоднозначных слов
- Градиентная эмоциональная шкала

**Пример:**
```json
{
  "sentiment": "positive",
  "sentiment_score": 0.989,
  "negative_prob": 0.003,
  "neutral_prob": 0.002,
  "positive_prob": 0.989,  // <- победитель
  "skip_prob": 0.004,
  "speech_prob": 0.002
}
```

### 5. ОТНОСИТЕЛЬНЫЕ ХАРАКТЕРИСТИКИ

Добавляются после обработки всех слов для сравнения с общими статистиками.

| Поле | Формула | Применение |
|------|---------|------------|
| `duration_relative` | duration / средняя_длительность | Поиск акцентированных (>1.5) или проглоченных (<0.5) слов |
| `rms_relative` | rms / средняя_громкость | Выделение громких/тихих моментов |
| `pitch_relative` | pitch_mean / средняя_высота | Определение интонационных подъёмов/спадов |

**Применение:**
- Нормализация данных для машинного обучения
- Поиск выбросов и аномалий
- Относительное сравнение характеристик

---

## 📊 Примеры использования

### Поиск эмоционально окрашенных слов
```python
emotional_words = [
    w for w in metadata['samples'] 
    if w['sentiment'] in ['positive', 'negative'] 
    and w['sentiment_score'] > 0.8
]
```

### Поиск акцентированных слов
```python
accented = [
    w for w in metadata['samples']
    if w['rms_relative'] > 1.5 and w['duration_relative'] > 1.2
]
```

### Поиск вопросительных фраз
```python
questions = [
    w for w in metadata['samples']
    if w['pitch_relative'] > 1.1  # повышение тона
    and w['word'] in ['что', 'где', 'когда', 'как', 'почему']
]
```

### Анализ темпа речи
```python
avg_duration = sum(w['duration'] for w in metadata['samples']) / len(metadata['samples'])
slow_words = [w for w in metadata['samples'] if w['duration'] > avg_duration * 1.5]
fast_words = [w for w in metadata['samples'] if w['duration'] < avg_duration * 0.5]
```

## 🎓 Термины и понятия

**RMS (Root Mean Square)** - среднеквадратичное значение амплитуды, показывает "энергию" звука

**Pitch (частота основного тона)** - основная частота колебаний голосовых связок

**MFCC** - коэффициенты, описывающие спектральную огибающую звука так, как её воспринимает человеческое ухо

**Spectral Centroid** - "центр тяжести" спектра, коррелирует с яркостью звука

**Zero Crossing Rate** - как часто сигнал пересекает нулевую линию, отличает вокализованные звуки от невокализованных

**Attack Time** - время, за которое звук достигает максимальной амплитуды

**Vosk** - система распознавания речи, предоставляет временные метки и confidence

**RuBERT** - русская версия BERT для анализа текста, обучена на русском корпусе

## 🔗 Связь характеристик

Разные характеристики связаны между собой:

- **Эмоции ↔ Акустика:** Позитивные слова часто имеют высокий pitch и rms
- **Части речи ↔ Длительность:** Глаголы обычно короче существительных
- **MFCC ↔ Фонетика:** Гласные и согласные имеют разные MFCC паттерны
- **Spectral flatness ↔ Тип звука:** Гласные ~0.01-0.1, согласные ~0.2-0.6
