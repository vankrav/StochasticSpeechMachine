# Установка модуля анализа эмоций

## Быстрая установка

```bash
# Активируйте виртуальное окружение
source .venv/bin/activate

# Установите новые зависимости
pip install transformers torch
```

## Что устанавливается

- **transformers** (~400MB) - библиотека Hugging Face для работы с трансформерами
- **torch** (~200MB) - PyTorch для запуска нейросетей
- **Модель RuBERT** (~500MB) - скачается автоматически при первом запуске

## Первый запуск

При первом запуске программа автоматически скачает модель:
```
sismetanin/rubert-ru-sentiment-rusentiment
```

Модель будет закэширована в `~/.cache/huggingface/` и в дальнейшем будет использоваться локальная копия.

## Проверка установки

```bash
python -c "import torch; import transformers; print('✓ OK')"
```

## Что анализирует модель

Модель определяет **sentiment** (эмоциональную окраску) каждого слова:
- **positive** - позитивное
- **negative** - негативное
- **neutral** - нейтральное

Также выдается:
- `sentiment_score` - уверенность модели (0-1)
- `neutral_prob`, `positive_prob`, `negative_prob` - вероятности для каждого класса

## Производительность

- **CPU**: ~0.05-0.1 сек на слово
- **GPU (MPS/CUDA)**: ~0.01-0.02 сек на слово

Для 500 слов добавляет ~25-50 секунд к общему времени обработки.
